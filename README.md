# Treasure Rush — Professional Runner UI v4

## GitHub Pages upload
Upload these four files directly into the **root** of the repository:

- `index.html`
- `style.css`
- `game.js`
- `README.md` (optional)

There must NOT be a `css/` folder unless you also move `style.css` into it and change the link accordingly.

## Important
`index.html` contains an inline copy of the CSS as a fallback, so the UI will still render if GitHub Pages temporarily fails to serve `style.css`. The external stylesheet is loaded as `./style.css?v=4` to avoid stale browser caching.

## Monetag
Add the exact Monetag SDK `<script>` generated by your Monetag dashboard before `game.js`, then set `MONETAG_AD_FUNCTION` in `game.js` to the exact generated global function name. Do not invent a zone ID.

Rewards are credited only when the configured rewarded-ad Promise resolves successfully. Real-money balances and withdrawals require server-side verification/backend logic; localStorage is only a demo balance store.
