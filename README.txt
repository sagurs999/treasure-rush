Treasure Rush Pro
1) Upload index.html, style.css and game.js to the same GitHub Pages folder.
2) In game.js set AD_ZONE_ID to your Monetag MAIN zone ID.
3) In index.html paste the exact Monetag SDK <script> tag from your Monetag dashboard.
4) Level completion shows a rewarded ad before the next level.
5) Rewarded ad completion adds +20 coins. The code does not add coins when the ad fails.
6) The +20 ad button can be used repeatedly whenever Monetag provides an ad.
